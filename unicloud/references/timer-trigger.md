# 定时触发 (Timer Trigger)

## 简介

云函数定时触发器用于定时/定期执行云函数。配置后会在相应时间点被自动触发，函数返回结果不会返回给调用方。

**适用场景：** 跑批任务、定时清理、数据同步、报表生成等。

## 超时时间

| 云厂商 | 定时触发最大超时 | 非定时触发超时 |
|--------|-----------------|---------------|
| 支付宝云 | 3 小时（需开启异步超时） | 180 秒 |
| 阿里云 | 600 秒 | 120 秒 |
| 腾讯云 | 900 秒 | 60 秒 |

## 触发间隔

| 云厂商 | 最短间隔 |
|--------|----------|
| 阿里云 | 1 分钟 |
| 支付宝云 | 1 秒 |
| 腾讯云 | 1 秒 |

## 配置方式

### 方式一：Web 控制台配置

在 uniCloud Web 控制台 → 云函数详情 → 创建触发器。

### 方式二：package.json 配置

```json
{
  "name": "function-name",
  "version": "1.0.0",
  "cloudfunction-config": {
    "triggers": [
      {
        "name": "my-trigger",
        "config": "0 0 2 * * * *"
      }
    ]
  }
}
```

## Cron 表达式

七个必需字段，按空格分隔：

| 排序 | 字段 | 值 | 通配符 |
|------|------|-----|--------|
| 第一位 | 秒 | 0-59 | `, - * /` |
| 第二位 | 分钟 | 0-59 | `, - * /` |
| 第三位 | 小时 | 0-23 | `, - * /` |
| 第四位 | 日 | 1-31 | `, - * /` |
| 第五位 | 月 | 1-12 | `, - * /` |
| 第六位 | 星期 | 0-6 (0=周日) | `, - * /` |
| 第七位 | 年 | 1970-2099 | `, - * /` |

> 支付宝云与阿里云的 cron 表达式不支持第七位（年），但在 package.json 内配置时仍需将第七位设置为 `*`。

### 通配符

| 通配符 | 含义 | 示例 |
|--------|------|------|
| `,` | 逗号分隔的并集 | `1,2,3` = 1点、2点、3点 |
| `-` | 范围 | `1-15` = 1号到15号 |
| `*` | 所有值 | `*` = 每个 |
| `/` | 增量 | `1/10` = 从第1个开始每隔10个 |

### 常用 Cron 示例

| 腾讯云 | 阿里云 | 支付宝云 | 说明 |
|--------|--------|----------|------|
| `0 * * * * * *` | `0 * * * * *` | `0 * * * * *` | 每1分钟 |
| `0 */10 * * * * *` | `0 */10 * * * *` | `0 */10 * * * *` | 每10分钟 |
| `0 0 * * * * *` | `0 0 * * * *` | `0 0 * * * *` | 每1小时（整点） |
| `0 0 18 * * * *` | `0 0 18 * * *` | `0 0 18 * * *` | 每天18:00 |
| `0 0 10,14,16 * * * *` | `0 0 10,14,16 * * *` | `0 0 10,14,16 * * *` | 每天10点、14点、16点 |
| `0 */30 9-17 * * * *` | `0 */30 9-17 * * *` | `0 */30 9-17 * * *` | 9-17点每半小时 |
| `0 15 10 * * 1-5 *` | `0 15 10 * * 1-5` | `0 15 10 * * 1-5` | 周一到周五10:15 |
| `0 0 2 1 * * *` | `0 0 2 1 * *` | `0 0 2 1 * *` | 每月1号凌晨2点 |

> 建议避免整点触发（特别是0点），错开高峰期。

## 云函数入参

定时触发时云函数收到特定参数：

### 腾讯云 & 支付宝云

```js
{
  "Time": "2023-01-01T00:00:00Z",
  "TriggerName": "my-trigger",
  "Type": "timer"
}
```

### 阿里云

```js
{
  "Time": "2023-01-01T00:00:00Z",
  "TriggerName": "my-trigger",
  "Type": "timer",
  "triggerName": "my-trigger",    // 旧字段，不推荐
  "triggerTime": "2023-01-01..."   // 旧字段，不推荐
}
```

## 云对象定时触发

> 新增于 HBuilderX 3.5.2

配置方式与云函数一致，定时触发时执行云对象的 `_timing` 内置方法：

```js
// index.obj.js
module.exports = {
  async _timing() {
    // 定时执行的逻辑
    console.log('定时任务执行', new Date())
  }
}
```

> 定时触发云对象时，`_before` 和 `_after` 均**不执行**。

## 注意事项

- 定时触发使用 **UTC+8** 时间
- 避免整点（特别是0点）触发，错开高峰期
- 阿里云运行时长超出配置时间时会重试 3 次
- 建议将开启定时触发的云函数超时时间配置为最大值
- 支付宝云设置定时触发后生效约有 1 分钟延迟
- package.json 中的配置只有云端部署才生效，本地运行不生效
- cloudfunction-config 不可删除云端配置（删除 package.json 中的 trigger 不会删掉云端触发器）
