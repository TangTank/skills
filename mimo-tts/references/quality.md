# 词库音频的内容验收

适用于用户反馈错读、重复、追加内容，或要求重新生成高正确性音频的任务。输出正确率依赖源文本、目标读法、合成与验收；没有任何提示词、时长阈值或单个识别模型能保证全部正确。

`choices[0].message.final_text_preview` 是润色后送入合成的文本，不是对实际音频的转写，不能用它证明没有重复、追加或错读。该字段仅在 `audio.optimize_text_preview: true` 时返回，而该开关仅支持 `mimo-v2.5-tts-voicedesign`；官方预置音色使用的 `mimo-v2.5-tts` 不适用。文档中的 `message.audio.transcript` 当前仅为 `null`。要求忠实原文的词库不为获取预览而开启润色；音频自动筛查仍应使用独立 ASR，并保留人工复核。

## 生成输入与复核依据

- 冻结每条的英文原文、业务 ID、文件名、口音及源数据位置，直接提交英文单词或例句给 TTS。无需提供音标，也不因音标缺失而阻塞生成；词性、义项和音标仅在针对具体问题复核时按需参考，不能要求先补齐全库。
- 同形异音词通常由例句语境帮助模型选择读法。发现孤立单词或例句的读法有歧义时，再针对该条核对，例如 `record` 的词性重音、`read` 的时态、`minute` 的义项；不把音标混入朗读文本，也不随便把第一个读音认定为唯一答案。若采用音素工具处理个别顽固错读，需另外核对其要求，不能直接假定原库记号是标准 IPA。
- 例句可能包含词典释义括号、编辑残留、缩写、数字或拼写错误。将可疑项列为源文本待复核；不擅自润色、删除说明或修改原文来提高识别匹配率。源文本有问题时不能只靠重新合成修复。

## 小批对照后再扩大

优先验证官方预置音色 `mimo-v2.5-tts`，仅在需要定制音色时再验证 `mimo-v2.5-tts-voiceclone`。使用显式 `Mia` 或 `Chloe`、`--kind word --instruction-mode faithful --pace normal` 做问题词对照：`user` 中提供词库场景、词典式中性朗读及只读一次要求，`assistant` 只保留原文。句子使用 `--kind sentence`，不把句子连读指令套到孤立单词。`educational` 和 `neutral` 可显式复现旧请求。模式效果需实测，音色名称也不保证英音或美音；小批试音不恢复已停止的全量任务。

代表性样本应包含历史坏音频、未用于调参的新词、短词、长词、同形异音词语境，以及短句、长句、缩写和数字。另保留有人工标签的正确及错误旧音频，用来检验验收器是否会漏掉已知错误；测试集之外的错误率不得外推。记录真实调用数、失败数和重试数，不把文件数当作验收通过数。

## 逐条筛查与复核

1. **文件与身份**：解码完整性、请求/音频哈希、ID/原文对应、异常静音及截断。时长只作为异常信号，不用“低于 3 秒”作为内容通过条件。
2. **独立转写**：用与合成分离的 ASR 识别完整音频，不向识别器提供目标单词、答案提示、前缀或热词。需要第二模型时选不同模型路线交叉检查；它们仍可能共同出错。原始转写与分词顺序必须保存，不能去重、删重复词、忽略尾部语音或模糊匹配后放行。
3. **逐词对照**：检查漏读、增加、重复、单复数及词尾。允许的大小写、标点、英美拼写、数字与缩写展开规则需预先声明。数字和缩写仅作明确的一对一等价，不能任意改写。短词/同音词的拼写误识别不能直接认定发音错误。
4. **发音与重音**：转写相同仍可能有错音或错重音；对照目标读法进行听审，必要时辅以音素评分或对齐。强制对齐得到时间戳并不证明声音符合目标文本，音素评分也不能当作人工真值。

至少区分 `generated`（生成成功）、`screened`（机器筛查未发现问题）、`needs_review`（疑似问题/不确定）和 `accepted`（按约定完成内容验收），并记录验收方法、人员或工具版本及音频哈希。若目标是每条都确认正确，需逐条由能判断目标口音与读法的人员听审；全自动流程只能降低风险，不能承诺 100%。只复核机器疑似项时，应清楚说明其余文件仅通过机器筛查。

若识别结果混入未在接口协议中说明的模板标记、语言标签或思考片段，应保留原始输出并记作识别异常；不能通过清洗这些内容来提高匹配数量，更不能直接把识别异常归因于合成音频。先用已知正确/错误的独立样本校验识别器。

## 重试和交付

对确定内容错误或不确定的条目保留旧候选，有限次重新合成，每个新候选重新完整验收。一般先试 2–3 个候选；仍失败时列入待处理，改用有发音词典/音素控制的引擎或人工录音等用户允许的办法。不能无限重试直到某次 ASR 碰巧匹配，也不能因没有好候选就放宽标准。

新批次使用独立输出目录，保留原有映射与原音；只把验收通过的指定候选写入交付清单。若采用压缩，先验原音，再统一本地压缩，压缩后复核完整性、绑定与关键听感，所有验收记录绑定最终文件哈希。上传或写数据库遵循用户实际授权。
